# RecoverAI - Backend API

FastAPI backend service for RecoverAI, built for Razorpay Track 3 (AI Revenue Recovery). It listens to Razorpay payment webhooks, triggers a Gemini AI agent to analyze payment failures, and programmatically generates automated recovery links via Razorpay APIs.

* **Tech Stack:** Python, FastAPI, PostgreSQL, Razorpay SDK, Google GenAI SDK.
